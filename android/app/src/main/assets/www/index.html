মেমরি: MXFF যা মনে রাখবে

    সাম্প্রতিক নোটিফিকেশন

    ফোনের নোটিফিকেশন পড়ুনSettings-এ "Notification access" দিতে হবে। শুধু ফোনেই থাকে।

    AI (GEMINI)

    Gemini API কীফ্রি কী পেতে aistudio.google.com/apikey খুলে Create API key চাপুন। কীটা শুধু এই ফোনেই থাকে। অন্য কোনো সার্ভার লাগে না।

    সাধারণ

    ভাষা
    ভয়েসে উত্তর
    লাগাতার কথোপকথনউত্তরের পর আবার শোনে।
    ফোনের কাজে স্ক্রিনশট দেখুকভিডিও ও ছবি বুঝতে সাহায্য করে। বন্ধ থাকলে শুধু স্ক্রিনের লেখা যাবে। কাজ না চললে কিছুই যায় না।

    ফ্লোটিং MXFF

    ফ্লোটিং অ্যাসিস্ট্যান্টসব অ্যাপের উপরে ছোট অর্ব। "Hey MXFF" বললে শোনে।
    Hey MXFF (অ্যাপ খোলা থাকলে)

    অনুমতি

    ফোন কন্ট্রোল চালাতে: Android 13+ হলে আগে "App info → Allow restricted settings", তারপর "ফোন কন্ট্রোল (Accessibility)"-তে MXFF AI চালু করুন। মেসেজ পাঠানো, ইনস্টল ও পেমেন্টের আগে MXFF সবসময় আপনার অনুমতি নেয়।
